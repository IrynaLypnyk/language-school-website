# Language School

Archived freelance website for a private language school, created for Eugene Miller Studio in 2018.

Built with HTML, CSS and vanilla JavaScript, with responsive layouts, AOS (Animate On Scroll), CSS animations and custom sliders.

[Live demo](https://language-school-ukr.netlify.app/)

This is a portfolio demo of a historical project and is not an active school website.

## Features

- Responsive Ukrainian-language landing page.
- Hero section with a background video and a poster fallback when autoplay is blocked.
- Custom looping photo and video sliders in each article, with previous/next controls.
- Video viewing overlay with native playback controls; videos pause when their panel closes or their slide becomes inactive.
- Scroll-triggered AOS animations, custom CSS animations and smooth anchor scrolling.
- Embedded Google Map showing the school's former location, with lazy loading.
